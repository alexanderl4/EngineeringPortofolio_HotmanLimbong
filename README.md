## 🛠️ Selected Engineering Experience

### 1. Offshore Structural & Weld Demand Assessment (LAPI ITB)
*   **Global Analysis:** Supported the global structural evaluation of an offshore helideck (5,000 kg MTOM classification) using Bentley SACS, focusing on member/tubular-joint unity checks and primary load-path tracking.
*   **Local FE Modeling:** Built high-fidelity substructure models (C1 and C2 skid supports) in Abaqus to run mesh-convergence studies and nonlinear static stress/plastic strain validations.
*   **Automation Routine:** Set up automated extraction paths for complex weld lines (10 C1 lines, 22 C2 split-edge segments) to integrate force/moment resultants and verify endpoint-closure limits before structural sizing checks.

### 2. Structural Analyst Internship (PT Turkish Aerospace Indonesia)
*   **Analytical Automation:** Scripted a Python utility using PyTables and Pandas to parse binary solver outputs (`.h5`, `.rpt`, `.f06`), automate Neuber and Ramberg-Osgood nonlinear corrections, and output clean Excel margins-of-safety summaries.
*   **Composite Failure Evaluator:** Engineered a data-array tool to screen shell elements across multi-ply laminates against seven distinct failure criteria (including Hashin, Puck, Tsai-Wu, and Max Strain).
*   **Impact Dynamics & Optimization:** Conducted explicit dynamic bird-strike evaluations (85 m/s SPH models) comparing aluminum vs. CFRP leading edges, and performed geometric trade studies on titanium scalloped lugs to trim component mass.

### 3. Structural Dynamics of Composite Propeller Blades (Undergraduate Thesis)
*   Investigated the harmonic response of an orthotropic sandwich blade configuration under rotational loading. 
*   Mapped centrifugal pre-stress adjustments using a Static General step with `NLGEOM` enabled, traced frequency shifting against engine-order lines via Lanczos extractions, and isolated critical hotspots for multi-axial ply stresses.
